# NCMS Frontend

WebApp interface for NCMS using Vue 3 + TypeScript + Vite.

## Tech Stack

- **UI Framework:** Vue 3
- **Language:** TypeScript
- **Build Tool:** Vite
- **Routing:** Pinia (optional)
- **HTTP Client:** axios

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Production Build

```bash
# Build for production
npm run build

# Preview the build
npm run preview
```
