# NCMS Infrastructure

Deployment and environment configuration for NCMS.

## Components
- Mosquitto broker with TLS/mTLS for device MQTT traffic.
- PostgreSQL/TimescaleDB initialization assets.

## Mosquitto mTLS Setup
1. Place or generate the persistent CA files in `mosquitto/certs/`:
   - ca.crt
   - ca.key
2. Place or generate the broker server certificate files in `mosquitto/certs/`:
   - server.crt
   - server.key
3. Start the broker:
   - docker compose up -d mosquitto
4. Device certificates are not pre-created in this folder. They are generated by
   the provisioning API during POST /api/v1/provision/register and returned
   over HTTPS.

## Mosquitto Config

Use `ncms-infra/mosquitto/mosquitto.conf` on the VPS or in Docker. It requires
the broker certificate to be signed by the same CA that the backend uses to
issue device certificates.

## Security Notes
- Registration response with PEM strings is acceptable without custom encoding,
  as long as transport is HTTPS/TLS and responses are not cached.
- Add Cache-Control: no-store for provisioning responses.
